01 Overview

WorldKey ("the Extension") is a browser extension for Google Chrome and Opera that provides proxy management, WebRTC leak protection, browser fingerprint configuration, and session management tools.

WorldKey does not collect, transmit, store, or share any personal data. All settings and configurations remain exclusively on your local device.

This Privacy Policy describes how the Extension handles information and explains what permissions it requires and why.

02 Data We Do Not Collect

WorldKey does not collect any of the following:

— Browsing history or visited URLs
— Cookies or session data from any website
— Proxy credentials (username, password)
— IP addresses or geolocation data
— Device identifiers or fingerprint data
— Personal information of any kind
— Analytics, telemetry, or crash reports
— Any data transmitted to external servers

The Extension has no backend server, no analytics integration, and no remote data collection of any kind.

03 Local Data Storage

WorldKey stores your settings locally using the browser's built-in chrome.storage.local API. This data never leaves your device.

Information stored locally includes:

— Proxy host, port, type, and scheme
— Proxy enabled/disabled state
— WebRTC protection policy preference
— Fingerprint configuration (timezone, language, screen resolution, etc.)
— Last checked external IP address and timestamp

You can delete all stored data at any time using the "Reset Settings" button in the Extension, or by removing the Extension from your browser.
04 Permissions & Justification

WorldKey requests the following browser permissions. Each permission is used exclusively for the stated purpose:

Permission Purpose
proxy Configure and control browser proxy settings (enable/disable proxy, set host/port/type).
privacy Apply WebRTC IP handling policy to prevent real IP address leaks through WebRTC.
webRequest
webRequestAuthProvider		 Automatically handle proxy authentication challenges without showing browser dialogs to the user.
storage Save user settings (proxy configuration, preferences) locally on the device.
tabs Read the current active tab's URL to show the domain in the Session Manager and apply session cleanup to the correct site.
cookies Remove cookies for the currently active website when the user clicks "Clear Session" in Session Manager.
browsingData Clear localStorage, sessionStorage, IndexedDB, cache, and service workers for the currently active website only, on explicit user request.
declarativeNetRequest
declarativeNetRequestWithHostAccess		 Modify the User-Agent HTTP request header as part of browser fingerprint configuration, when enabled by the user.
<all_urls> Required for webRequest proxy authentication handler to intercept proxy auth challenges on any domain. The Extension does not read or store content from any webpage.
05 Third-Party Services

WorldKey uses a single external service for IP verification:

api.ipify.org — a public, free IP lookup service. When you click "Check IP", the Extension makes a request to this service to retrieve your current external IP address. No personal data is sent; only a standard HTTP request is made.

The Extension does not integrate with any analytics platforms, advertising networks, or third-party data processors.

06 Fingerprint Manager

The Fingerprint Manager feature modifies certain browser API values (timezone, language, screen resolution, User-Agent, Canvas, WebGL, AudioContext, hardware parameters) to reduce browser fingerprinting by websites.

All fingerprint settings are configured and stored locally. The Extension does not transmit fingerprint data to any server. These modifications are applied in your browser only and affect how websites see your browser's properties.

The user retains full control and can disable fingerprint spoofing at any time via the Extension popup.

07 Session Manager

The Session Manager clears cookies, local storage, session storage, IndexedDB, cache, and service workers for the website currently open in your active browser tab.

This action is performed entirely within your browser. No data is transmitted externally. The cleanup applies only to the specific website domain shown in the button — other websites and your passwords are never affected.

08 Children's Privacy

WorldKey is not directed at children under the age of 13. We do not knowingly collect any information from children. As no data is collected by this Extension from any user, this applies equally to all age groups.
